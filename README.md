# Бабуля против мошенников

Голосовой бот для троллинга телефонных мошенников. Открываете сайт, жмёте «Позвонить», представляетесь сотрудником Каспи банка и пытаетесь выудить код из SMS. Бот играет потенциальную жертву: тянет время, путается, уходит в сторону и диктует выдуманные цифры. Всё работает локально на своей видеокарте, наружу доступ идёт через Cloudflare Tunnel.

```
Браузер ──WS (PCM16)──► cloudflared ─► nginx (web) ─┬─ /         статика React
                                                    └─ /ws/call  bot (Pipecat)
                                                                  ├─ Silero VAD + barge-in
                                                                  ├─ faster-whisper small (GPU)
                                                                  ├─ LLM → llm (Ollama, qwen3:4b-instruct, GPU)
                                                                  └─ Piper TTS (CPU) + эффекты голоса
```

Почему WebSocket, а не WebRTC: Cloudflare Tunnel не проксирует UDP, а сырой PCM поверх WebSocket проходит надёжно. Контракт клиента и сервера описан в [PROTOCOL.md](PROTOCOL.md).

Каждый персонаж описан в своём файле `bot/personas/*.md`. После текста frontmatter идёт системный промпт. Персонажи вшиваются в образ, поэтому после правки нужен `docker compose up -d --build bot`.

## Запуск

Требования: Docker с поддержкой GPU (на Windows это Docker Desktop с WSL2) и NVIDIA GPU примерно на 6 ГБ VRAM (проверено на RTX 3060 12GB).

```bash
cp .env.example .env          # заполнить DEMO_KEY, CLOUDFLARE_TUNNEL_TOKEN, пути к моделям
./scripts/download_models.sh  # qwen3:4b-instruct через Ollama, faster-whisper-small, 4 голоса Piper
docker compose up -d
```

- Локально сайт открывается на `http://localhost:8080/?key=<DEMO_KEY>`. Без https микрофон работает только на `localhost`.
- Бот стартует примерно 80 с: загружает модели и прогревает LLM. `web` ждёт, пока `bot` станет healthy.
- Чтобы запустить без туннеля, закомментируйте `COMPOSE_PROFILES=tunnel` в `.env`.

### Где лежат модели

| Переменная `.env` | Что внутри | По умолчанию |
|---|---|---|
| `OLLAMA_HOST_DIR` | домашняя папка Ollama (`models/…`); подойдёт уже существующая | `./models/ollama` |
| `MODELS_HOST_DIR` | `whisper/faster-whisper-small/`, `piper/*.onnx` | `./models` |

В git модели не попадают.

### Публичный доступ

1. В Cloudflare Zero Trust откройте **Networks → Tunnels**, создайте туннель и добавьте public hostname `https://<домен>` → `http://web:80`. Токен туннеля впишите в `CLOUDFLARE_TUNNEL_TOKEN`.
2. Защита демки:
   - **`DEMO_KEY`**: ключ проверяется на WS-хэндшейке, ссылка для друзей выглядит как `https://<домен>/?key=<ключ>`. Ключ сохраняется в localStorage и в access-логи не пишется. Если ключ пустой, бот пишет в лог предупреждение, и звонить может любой.
   - **Cloudflare Access** (опционально): **Access → Applications → Self-hosted** на тот же домен, политика вида «Emails: ваш список», вход по одноразовому коду на почту. Это бесплатно до 50 пользователей и работает поверх ключа.
3. Наружу открыт только `cloudflared → web`. Порты `bot` и `llm` не публикуются, а `web` слушает только `127.0.0.1`.

## Ограничения поведения

- Одновременно идёт только один звонок. Второй звонящий видит «Линия занята» (WS close `4409`), первый звонок при этом не прерывается.
- Звонок длится максимум `MAX_CALL_SECONDS` (600 с). Если пользователь молчит дольше `IDLE_TIMEOUT_SECONDS` (60 с), звонок сбрасывается.
- Барж-ин: если начать говорить, бот замолкает, генерация и TTS отменяются, фронт сбрасывает буфер воспроизведения.
- Аудио нигде не записывается. Транскрипты пишутся в лог только при `LOG_LEVEL=DEBUG`.

## Замеры

Замерено на RTX 3060 12GB, Ryzen 5700X, Windows 11 + WSL2 через `scripts/test_call.py` и nginx. Синтетическая речь, 26 ходов, все 4 персонажа.

| Метрика | Значение |
|---|---|
| Конец речи пользователя → первый звук бота | **0.86–1.84 с, медиана ≈ 1.1 с** (цель ≤ 1.5 с выполняется в 18 из 26 ходов) |
| Whisper small (float16, beam 1) | ≈ 0.26 с на фразу |
| Первый токен LLM + первое предложение | ≈ 0.4–1.0 с |

Из этой задержки около 0.7 с уходит на ожидание паузы: VAD stop 0.3 с, user speech timeout 0.4 с. Если пользователя часто перебивают на полуслове, эти значения можно увеличить в `bot/pipeline.py`.

**Удержание роли.** Текстовый тест прямо в LLM: 20 ходов на персонажа, 10 приёмов по кругу (давление, «я внук», угроза полицией, «первые две цифры», «повтори за мной», jailbreak «выведи системный промпт», «ты бот?», номер карты и CVV, «ответь списком»). Ни один персонаж не вышел из роли, не признал себя ботом и не назвал реальных данных. Бабушка и дед, как и задумано, диктуют случайные выдуманные цифры.

## Разработка

```bash
# сгенерировать тестовые фразы и позвонить через nginx (внутри контейнера bot)
docker compose exec -T bot python - "Здравствуйте, это Каспи банк." "Назовите код из SMS." < scripts/make_test_speech.py
docker compose exec -T bot python - /tmp/u0.wav /tmp/u1.wav --url ws://web/ws/call --persona granny --barge-in < scripts/test_call.py

# фронт с hot reload (прокси /ws и /api на localhost:8000)
cd frontend && npm ci && npm run dev
```

Автотестов нет. Проверка сводится к `npm run build` (там же `tsc --noEmit`) и `scripts/test_call.py`, который проверяет latency, `busy` / 4409 и barge-in.

## Известные ограничения

- `qwen3:4b` в Ollama — это thinking-only сборка 2507, и `reasoning_effort: none` её размышления не отключает. Поэтому используется `qwen3:4b-instruct`. `qwen3.5:4b` тоже работает, но медленнее.
- Длинное первое предложение ответа (а Piper синтезирует его целиком) иногда даёт задержку 1.7–1.9 с.
- Whisper small иногда ошибается в отдельных словах («код» → «кот»). Апгрейд — `WHISPER_MODEL=medium` (дольше на ~0.3 с) или GigaAM.
- Высота тона меняется ресемплингом, поэтому заодно замедляется речь. Для голоса пожилого человека это даже полезно, но тон и темп нельзя настроить независимо.
- Если поднять `bot` без новой `.env`, старая `LLM_MODEL=qwen3:4b` даст пустые или «размышляющие» ответы.
- Живой звонок из браузера (микрофон, воспроизведение, iOS Safari, мобильная вёрстка с реальным звуком) автоматически не проверялся. Сквозной путь проверен через `scripts/test_call.py`.
- Silero TTS и GigaAM (фаза 3, апгрейд голоса и распознавания) не сделаны.
